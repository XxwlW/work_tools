```python
from dataclasses import dataclass, field

@dataclass
class Point:
    x: float
    y: float

@dataclass

    x: float
    y: float
    yaw: float

@dataclass
class FrameData:

    seq_num: int = -1

    car_pose: Pose = None

    slot_pts: list[Point] = field(default_factory=list)

    pdc_left: list[Point] = field(default_factory=list)
```


作为结束标记。

实现：

```python
def split_frames(lines):

    frames = []
    current = []

    for line in lines:

        current.append(line)

        if "Current frame end." in line:
            frames.append(current)
            current = []

    return frames
```

建议：

```python
def valid_pt(x, y):

    if math.isnan(x):
        return False

    if math.isnan(y):
        return False

    if abs(x) > 50000:
        return False

    if abs(y) > 50000:
        return False

    return True
```

# 六、解析器实现

## 通用点集解析

适用于：

```text
BSegData
NSegData
FusSegData
```

例如：

```text
=FusSegData==(FusNum(23),
0(7302.44,-6820.85),
1(6119.22,-6534.32)
...
)
```



解析：

```python
import re

POINT_RE = re.compile(
    r'\d+\((-?\d+(?:\.\d+)?),(-?\d+(?:\.\d+)?)\)'
)

def parse_points(text):

    pts = []

    for x, y in POINT_RE.findall(text):

        x = float(x)
        y = float(y)

        if valid_pt(x, y):

            pts.append(
                Point(
                    x / 1000.0,
                    y / 1000.0
                )
            )

    return pts
```
