这是我根据我们整个讨论过程整理出来的 **《APA Debug Viewer 需求说明 + 日志字段规范 + 开发注意事项》**。

后续无论你自己实现，还是交给 Claude、GPT、Copilot、Cursor，都可以直接作为项目说明书使用。

---

# 一、项目目标

开发一个：

```text
APA Debug Viewer
```

用于分析自动泊车（APA）日志中的：

```text
建图(Mapping)
融合(Fusion)
边界(Boundary)
OD
规划(Planning)
泊出(ParkOut)
```

数据。

最终效果类似：

```text
Apollo DreamView
+
RViz
+
APA专项调试工具
```

---

# 二、核心需求

日志：

```text
连续Frame
```

形式。

例如：

```text
Frame1

...
Current frame end.

Frame2

...
Current frame end.

Frame3

...
Current frame end.
```

系统需要：

```text
解析日志
 ↓
生成FrameData
 ↓
构建Scene
 ↓
渲染
 ↓
支持回放
```

---

# 三、日志特点

## Frame结束标志

唯一可信标志：

```text
Current frame end.
```

出现即表示：

```text
当前Frame结束
```

---

## SeqNum

未来日志中存在：

```text
Planning seq_num
```

或者：

```text
seq_num
```

用于：

```text
Frame编号
Timeline
Frame跳转
```

# 四、坐标系说明

## 所有点数据

日志输出：

```text
mm
```

单位。

例如：

```text
2350
```

表示：

```text
2.35m
```

---

## Viewer内部统一

进入系统立即转换：

```python
mm -> m
```

禁止后续再转换。

统一：

```python
Point.x
Point.y
```

全部为：

```text
meter
```

```

保持原始顺序
```

# 七、Fusion相关字段

日志存在：

```text
==PDCFusionSubLaneSuccess==

==FSDFusionObj1Success==

==FSDFusionObj2Success==

==SDGFusionObj1OuterBorderSuccess==
```

表示：

```text
Fusion Stage
```

---

每个Stage下面固定出现：

```text
BSegData

BSegNum

NSegData

NSegNum

FusSegData

FusSegNum
```

结构。

---

含义：

## BSegData

```text
原始边界点
```

Base Segment

---

## NSegData

```text
新增边界点
```

New Segment

---

## FusSegData

```text
融合结果
```

Fusion Segment

---

Num表示：

```text
对应点个数
```

例如：

```text
BSegNum(15)
```

表示：

```text
15个点
```

---

# 九、Boundary相关

未来需要支持：

## MainBoundary

来源：

```c
main_boundary
```

6个点。

---

结构：

```text
P0
P1
P2
P3
P4
P5
```

形成：

```text
U型边界
```

---

对应：

```c
RightBoundary
```

或者：

```c
LeftBoundary
```

取决于：

```c
is_slot_at_right
```

---

## SubBoundary

来源：

```c
sub_boundary
```

2个点。

---

形成：

```text
对向边界
```

即：

```text
道路另一侧边界
```

# 十二、Frame数据模型

建议统一：

```python
FrameData
```

---

结构：

```python
@dataclass
class FrameData:

    seq_num:int

    current_pose:Pose

    goal_pose:Pose

    slot_pts:list[Point]

    left_pdc:list[Point]

    right_pdc:list[Point]

    fusion_stages:list[FusionStage]

    boundaries:list[Boundary]
```

# 十六、必须保留的原始信息

未来排查问题需要：

```text
点索引
```

因此：

不要只保存：

```python
Point
```

建议：

```python
@dataclass
class IndexedPoint:

    idx:int

    x:float

    y:float
```

---

这样后续可以显示：

```text
FusSeg[12]

BSeg[5]
```
