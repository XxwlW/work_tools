# main.py

最终入口。

```python
def main():

    text=open(log).read()

    frames=FrameSplitter().split(text)

    parser=FrameParser()

    all_frames=[]

    for frame in frames:

        all_frames.append(
            parser.parse(frame)
        )

    renderer=PlotlyRenderer()

    renderer.render_frames(
        all_frames
    )
```

# 我个人最推荐的下一步

不要先写 Dash。

先完成：

```text
日志
 ↓
FrameData
 ↓
Plotly
 ↓
HTML
```

即：

```bash
python main.py log.txt
```

生成：

```text
output/frame_0001.html
```

当这些都稳定后，再把 Plotly Figure 嵌进 Dash。

这样开发速度最快，而且后面接 Boundary、OD、Path、泊出边界（你前面发的那段 C 代码生成的 MainBoundary/SubBoundary）都不用重构。
