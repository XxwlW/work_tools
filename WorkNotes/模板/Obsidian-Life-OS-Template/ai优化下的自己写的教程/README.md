# AI 优化下的自己写教程

这组教程的目标不是让用户背格式，而是让用户理解这套写法为什么可以先松后紧：

> 先像聊天一样写下来；需要被系统看见的对象，加上链接；需要被计算的东西，再补值、标签和关键字。

每一页都先讲机制，再给可以复制的 Markdown。文档图面会直接放入例子、中文标注和系统理解结果，原 Obsidian 截图只作为真实界面对照。
