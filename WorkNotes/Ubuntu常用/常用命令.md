# Python 使用 update-alternatives 管理系统级默认版本

这个方法允许你在系统已安装的多个 Python 版本之间切换全局的 Python 和 python3 符号链接。适合需要为所有用户固定一个主要版本的场景。

步骤：

安装你需要的 Python 版本（以 Python 3.8 和 3.10 为例）：



```bash
sudo apt update
sudo apt install python3.8 python3.8-venv # 安装解释器和venv模块
sudo apt install python3.10 python3.10-venv

```

现在你的系统同时安装了 python3.8, python3.10 和系统自带的（例如 python3.12）。你可以用 python3.8 --version 来验证。

将各个版本加入到 update-alternatives 系统中：

设置 python3 的替代组

```bash
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.8 1
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.10 2
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.12 3  # 系统自带版本
```

如果也需要管理 pip3，同样可以设置（可选）

```bash
sudo update-alternatives --install /usr/bin/pip3 pip3 /usr/bin/pip3.8 1
sudo update-alternatives --install /usr/bin/pip3 pip3 /usr/bin/pip3.10 2
```

--install <链接> <名称> <路径> <优先级>：优先级数字越大，越可能被选为自动模式下的默认选项。

查看和切换版本：

```bash
# 查看当前可用的所有 python3 版本

sudo update-alternatives --config python3

# 查看当前可用的所有 pip3 版本（如果设置了）

sudo update-alternatives --config pip3
运行命令后，会出现一个交互式菜单：

```

```text
  Selection    Path                 Priority   Status
------------------------------------------------------------

* 0            /usr/bin/python3.12   3         auto mode
  1            /usr/bin/python3.10   2         manual mode
  2            /usr/bin/python3.12   3         manual mode
  3            /usr/bin/python3.8    1         manual mode

Press <enter> to keep the current choice[*], or type selection number:
输入你想要切换到的版本前面的数字（例如 1），然后按回车。
```

验证切换是否成功：

```bash
python3 --version

输出应该是 Python 3.10.x
```
