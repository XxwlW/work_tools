# 笔记生成 6 步标准流程（v4 极简版）

## Step 1：数据核验
- **必须**：用 webfetch / GitHub API / Jina Reader 核验所有 2026 年数字（stars / 周活 / 版本号）
- **禁止**：编造公司背景、融资数据、用户量
- **核验来源**：Wikipedia、官方博客（Anthropic / OpenAI / Google）、GitHub API、Claude 训练数据
- **未核实数据**：标"未核实"或写"模糊表述"，不要直接发绝对数字

## Step 2：写笔记（3 个版本）
- **完整版**：约 1500-2000 字，含数据表格、互动话术、出图指南
- **精华版**：800 字版本（小红书标准图文长度）
- **单文件存放**：每个 day 一个目录 `内容/dayN/`，含完整版 + 精华版

## Step 3：6 张图 Prompt（核心规范）
- **数量**：6 张（封面 + 4 知识点图 + 互动图）或按需要增减
- **格式**：每个 Prompt 一个独立 `.md` 文件，放在 `prompts/` 子目录
- **v2 模式（必用）**：中英混合 Prompt，**直接含中文**，AI 生成时即画出中文字
- **不要让 AI 后期填字**（容易出现"鬼画符"）

## Step 4：v4 极简封面（必用！基于小红书官方诊断）
- **1 个核心视觉主体**（不要堆 5 个机器人 / 4 个图标）
- **大标题占画面 1/3**
- **元素数量 ≤ 5 个**
- **文字段数 ≤ 3 段**
- **4 角水印**：`知识猫 × AI 测评日记`（IP 标识）
- **下期预告徽章**（右下角，红色）
- **来源**：2026-06-07 小红书诊断报告——"封面点击率 7% 仅超 5% 同类"的解决方案

## Step 5：中文校对（必做）
- **工具**：Python 脚本，提取 `## 中文文字内容` 区块
- **检查项**：错别字、多余空格、半角符号混入
- **目标**：0 错别字 / 0 多余空格 / 0 半角符号
- **示例脚本位置**：`xhs/day*/出图指南.md` 末尾的报告

## Step 6：出图指南
- 每个 day 一个 `出图指南.md`
- 含：v4 极简封面章节、6 张图清单、5 平台操作（即梦/可灵/MJ/DALL-E/SD）、成本对比、错字修复技巧
- 同步标注：哪些 Prompt 已更新到 v4

# v4 极简封面标准（统一规范）

| 要素 | 标准 |
|------|------|
| **大标题** | 占画面 1/3 |
| **视觉主体** | 1 个核心（人物对决 / 太空龙虾 / 老板 vs 管理者） |
| **元素数量** | ≤ 5 个 |
| **文字段数** | ≤ 3 段 |
| **4 角水印** | "知识猫 × AI 测评日记" |
| **下期预告** | 右下角红色徽章（"下期：XXX"） |
