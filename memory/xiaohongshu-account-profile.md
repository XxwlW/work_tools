## 爆款公式（3 大要素）

1. **数字党**：标题含具体数字（"37.7 万 / 5 个 / 3 步 / 70%"）
2. **AI 工具 / Agent / 政策类干货**：与账号"强 AI 工具属性"匹配
3. **对比表 / 横评 / 5 选 1**：3-5 个对象对比 = 流量密码

## 内容红线（必避）

- ❌ **教程类**（"0 成本起号"/"7 天涨粉"）→ 自己账号未跑通，承诺 = 翻车 → [[no-tutorial-without-data]]
