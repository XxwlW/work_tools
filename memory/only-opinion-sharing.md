写小红书笔记时，**只做"观点/信息/解读/盘点"分享，不做"工作/机会/职业/副业/月入"等推荐类内容**。

**Why**：
- 2026-06-07 用户反馈："正文里的【5 个新机会】（直接抄）也不合适太直接了，没有实际调研的这种工作推荐相关的不要出现，只做观点分享"
- 推荐型内容（"5 个新机会"、"月入 5K-3W"、"上手教程"）= 对读者承诺"我说的靠谱"
- 没调研 = 误导读者 = 评论区被打脸 = 信任反噬 = 账号降权
- 账号当前状态：day11 涨粉 0、爆款未稳定、自身未跑通任何"机会"

**How to apply**：
- ✅ **只做观点分享**：政策解读 / 概念科普 / 资讯盘点 / 工具横评 / 趋势观察 / 行业新闻评论
- ❌ **避免做**：5 个新机会 / 月入 X 万 / 副业推荐 / 职业建议 / 教程 / 攻略 / "怎么做" / "上手"（"直接抄"也算）
- 校验方法：每写完一段，问"这是观点/事实，还是推荐/承诺？"如果是后者，删掉或改写
- 改写示例：
  - "5 个新机会直接抄" → "5 个被频繁提及的方向（仅作盘点）"
  - "月入 5K-3W 副业" → "听说这个方向有人月入 5K-3W（未经核实）"
  - "手把手教你" → "我看到的玩法是 XXX"
