写小红书笔记时，**教程类内容（如"0 成本起号"、"7 天涨 XXX 粉"）需要自己账号已经有真实跑通的数据**。

**Why**：
- 2026-06-07 用户反馈："自己账号都差的很，怎么能出教程？"
- 账号当前状态：day11 涨粉 0、互动极低、爆款未稳定复现
- 出教程 = "半桶水"，无说服力、评论区易被打脸
- 写"教程" = 对读者承诺结果，承诺落空 = 信任反噬

**How to apply**：
- ✅ **可以写**：测评 / 横评 / 复盘 / 资讯解读 / 工具盘点（这些是"分享信息"，门槛低）
- ❌ **避免写**：教程 / 攻略 / "7 天 / 0 成本" / "手把手教你" / "我是怎么做到的"（这些是"承诺结果"，需有真实数据）
- 选题校验：**如果笔记标题/副标含"教程 / 教你 / 0 成本 / 7 天"等承诺词，必须有账号自身的实跑数据支撑**
- 替代方案：把"教程"改成"测评/横评/复盘"——比如"AI 数字人 0 成本起号教程" → "5 个 AI 数字人工具横评"
