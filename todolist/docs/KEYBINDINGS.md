# 快捷键

> MVP 仅基础快捷键；全局热键/自定义快捷键在 Phase 2。

| 快捷键 | 作用 | 范围 |
|---|---|---|
| `Ctrl + N` | 新建任务 | 全局 |
| `Ctrl + T` | 切换浅/深主题 | 全局 |
| `F5` | 刷新 | 全局 |
| `Enter` | 保存 | 任务表单内 |
| `Esc` | 取消 | 任务表单内 |
| 双击任务 | 编辑任务 | 任务列表 |
| `✎` | 编辑任务 | 单条任务右侧 |
| `✕` | 删除任务 | 单条任务右侧 |
| `↺` | 恢复归档分类 | 侧栏已归档区 |

## 计划中（Phase 2）

- `Ctrl + Shift + Space` 全局唤起浮层输入（注意会与中文输入法冲突，待 Phase 2 决策）
- `Ctrl + 1/2/3` 切换侧栏视图（全部/今日/已完成）
- `Esc` 关闭浮层
