Blackwell B200 出货延迟已解决，**2026 H2 主力**。★★

### ② HBM（高带宽存储）
- **市场结构**：2024 年 HBM 全球市场 **$18B** → 2026E **$80B**（CAGR 110%）
- **三家分天下**：SK Hynix 50% / Samsung 40% / Micron 10%
- **2026 H2 缺口**：行业整体产能缺口约 **30-50%**（TrendForce 数据）
- **HBM4 标准**：2026 年量产，**单颗容量从 36GB → 48GB**，带宽 1.2TB/s
- ★★★ 多源（TrendForce / 集邦 / 韩媒 / SK Hynix 财报）

### ③ CoWoS 封装（最稀缺环节）
- **TSMC 独家**，2024 月产 1.5 万片 → 2025 月产 3.5 万片 → **2026 月产 4.5 万片**
- **产能仍紧张**：订单排队到 **2027 年**
- **中国大陆追赶**：长电科技 / 通富微电 2026 量产 2.5D 封装，但良率仅 50-60%（TSMC 90%+）
- ★★★ 多源（TSMC 法说会 / 摩根士丹利 / 中信证券）

### ④ 光模块
- **速率迭代**：400G → 800G → **1.6T（2026 H2 量产）**
- **市场结构**：2024 全球 **$45B** → 2026E **$90B**
- **A 股龙头**：中际旭创（全球第一，份额 30%）/ 新易盛 / 天孚通信 / Coherent（美）
- ★★★（Lightcounting / 中际旭创财报）

### ⑤ 液冷
- **传统风冷失效**：单机柜功率从 10kW → 50kW+（GB200 NVL72），必须液冷
- **市场结构**：2024 **$5B** → 2026E **$30B**（CAGR 144%）
- **A 股龙头**：英维克 / 高澜股份 / 申菱环境
- ★★（Vertiv 财报 / IDC 报告）

### ⑥ 电源
- **800V HVDC 趋势**：传统 54V 配电不够，2026 起 800V 直流成为新数据中心标配
- **市场结构**：2024 **$15B** → 2026E **$35B**
- **A 股龙头**：麦格米特 / 欧陆通 / 台达（台）
- ★★（台达法说会 / 中国电源学会）

### ⑦ PCB / 载板
- **AI 服务器 PCB 单机价值**：从普通服务器 $200 → AI 服务器 **$2,000+**（10 倍）
- **M8 级别覆铜板**：2025 涨价 50%+（生益科技 / 南亚 PCB）
- **A 股龙头**：沪电股份 / 胜宏股份 / 鹏鼎控股
- ★★（Prismark 报告 / 沪电法说会）

### ⑧ 服务器
- **AI 服务器占整体份额**：2024 15% → 2026E 45%
- **市场结构**：2024 **$200B** → 2026E **$500B**
- **代表公司**：工业富联（鸿海系）/ 浪潮信息 / Supermicro / Dell
- ★★（IDC 报告）

### ⑨ EDA / IP
- **AI 驱动 EDA 升级**：Synopsys / Cadence 2026 推 AI 辅助设计 EDA
- **市场结构**：2024 **$15B** → 2026E **$25B**
- **代表公司**：Synopsys / Cadence / 华大九天
