## 5 段式结构 · day15 实例

### 实例 1：封面（15.1）

```yaml
文件:    xhs/内容/day15/prompts/15.1-封面-两会新词智能经济.md
模板:    01-cover.md
图型:    封面
调性:    政策类 → 暖白 + 中国红 + 焦糖橙
字数:    5 段式 + 平台参数 + 9 项校对 checklist
亮点:
  - 强化"政策翻译官 Vol.01"系列编号
  - 3 个数字标签（2027/70%/3 观察）
  - 完全脱离政府符号（无国徽/无文件 icon）
```
