# 小红书 AI 科普配图 Prompt 体系

## Overview

为「Neural | 奇点 × AI 测评日记」账号生成 3:4 竖版配图 Prompt。
**核心特征**：5 段式文件结构 + 5 种图型模板 + 平台参数对照 + 红线清单 + 中文校对 SOP。

15 篇笔记验证过：即梦/可灵中文错字率 < 5%，Midjourney ~30% 慎用。

## When to Use

- 用户要做一期 dayN 小红书笔记，需要 5 张图的完整 Prompt
- 用户要批量出某主题的封面 / 对比图 / 数据图 / 互动图
- 用户在 xhs/内容/dayN/prompts/ 下要新写一份 `N.M-类型-XXX.md`
- 需要把 day11/day15 的成熟 Prompt 改写到新选题

**不要在以下情况使用**：
- 用户要做"教程/0 成本/月入"承诺型内容（账号红线）
- 用户要加橘猫 / 知识猫 / 萌系动物 IP 元素（已被禁，见 memory）
- 用户要"姐妹/家人们"开头（中性化红线）

## 5 段式文件结构（必遵守）

每个 Prompt 文件 `.md` 必须按以下顺序写：

```
① 中文文字内容（已校对清单）   ← 列出所有要出现的中文+emoji
② 优化依据                      ← 1-3 行说为什么这样设计
③ 主体英文 Prompt（中英混合）   ← 直接复制到 MJ/即梦/可灵
④ 平台参数                      ← MJ 参数 / 即梦尺寸 / DALL-E 尺寸
⑤ 中文校对 checklist            ← 出图后逐字核对（用 [ ] 框）
```

## 文件命名规范

```
{N}.{M}-{类型}-{核心信息}.md
例：
  15.1-封面-两会新词智能经济.md
  15.3-软硬智能体对比.md
  15.6-互动图-评论区扣1-5.md

N = 第几期
M = 第几张图 (1-6)
类型 = 封面/概念/数据/对比/观察/互动
```

## 平台参数对照

| 平台 | 比例 | 关键参数 | 中文错字率 |
|---|---|---|---|
| **🥇 即梦** | 3:4 竖版 | 选 3:4 比例 | **< 5%** 最推荐 |
| **🥇 可灵** | 3:4 竖版 | 选 3:4 比例 | **< 5%** 最推荐 |
| ✅ DALL-E 3 | 1024x1792 | 选 1024x1792 | ~10% |
| ⚠️ Midjourney | `--ar 3:4` | `--ar 3:4 --stylize 150 --niji 6` | ~30%（中文易错）|

## 5 大红线（出图前必检）

```
❌ 不要橘猫 / 知识猫 / 任何动物 IP 元素
   → memory 校正：用户已禁知识猫 IP
❌ 不要机器人脸 / 二次元萌妹
   → 与"克制漫画气质"人设冲突
❌ 不要科技蓝紫 / 霓虹色
   → 调性是"暖白 + 焦糖橙 + 深灰黑"
❌ 不要政府符号 / 国徽 / 文件 icon
   → 政策类合规风险
❌ 不要"姐妹/家人们"开头
   → 账号未跑通前中性化

✅ 可加：手账风 / 胶带 / 便利贴 / 钢笔线稿 / 米色纸张
✅ 可加：中国红 + 焦糖橙 + 深灰黑（政策类）
✅ 可加：天空蓝 + 焦糖橙（科普类）
```

## 视觉调性（已验证）

- **比例**：3:4 竖版（小红书标准）
- **背景**：暖白 / 米黄牛皮纸
- **线稿**：深棕钢笔 / 深灰黑墨水
- **配色**：焦糖橙（主强调）+ 天空蓝（辅）+ 中国红（重音）+ 少量珊瑚红 / 奶油黄
- **避免**：高饱和霓虹 / 彩虹 / 科技蓝紫
- **风格参考**：日系青年漫画 / Apple editorial / 独立插画 / LOOK BACK

## 出图后 5 步校对 SOP

```
1. 中文逐字检查（重点：数字、人名、英文 vs）
2. emoji 是否正确显示（火/星星/箭头）
3. 关键词是否醒目（标题/数字/品牌名）
4. 比例是否 3:4 竖版
5. 特殊检查：
   - 政策类：原文表述不能错
   - 数据类：数字必须对得上
   - 人物类：是否踩人设红线
```

## Quick Reference

### 封面要素速查
- 顶部小字：`【IP 编号 Vol.NN】`
- 主标题 ≤ 8 字
- 副标题 ≤ 14 字
- 3 个数字标签（橙 / 红 / 灰三色）
- 底部水印：`Neural | 奇点 × AI 测评日记`

### 对比图要素速查
- 主标题 + 来源/署名
- 左右两栏 + 中间 VS
- 双色对照（蓝 vs 橙）
- 底部金句

### 互动图要素速查
- 主标题 + 副标题
- 中心人物（无 IP）
- 3 个评论气泡（不同边框色）
- 3 行系列预告（Vol.N+1/2/3）
- "评论区见～" 引导

## Common Mistakes

1. **跳过中文内容清单** → 出图后逐字校对困难，错字率高
2. **使用 `--v 6` 而非 `--niji 6`** → niji 风格更适合手账风
3. **不写校对 checklist** → 中文错字进入正文
4. **加入橘猫 / 萌系 IP** → 触红线（memory 已校正）
5. **直接用 Prompt 平台而忘了 5 段式结构** → 不利于后续复用

## Real-World Impact

一个完整的 dayN 配图流程：
1. 收资：用户提供主题 / 选题
2. 选型：从 5 模板中选 5 张图型
3. 写文件：按 5 段式结构生成 `N.M-类型-XXX.md` × 5
4. 出图：用即梦/可灵出 3:4 竖版
5. 校对：逐字核对中文 checklist
6. 发布：发到 xhs/内容/dayN/1.png ~ 5.png
