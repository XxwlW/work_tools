# 小红书科普笔记创作技能

## Overview

将技术概念转化为通俗易懂、适合小红书传播的科普笔记。核心方法是"降维翻译"——把晦涩的技术内容转化为目标受众能一眼看懂的大白话，配合统一视觉风格的手账风配图，实现高传播、高互动。

## When to Use

- 用户提供了某个技术概念（AI、Agent、模型蒸馏等），需要转化为小红书科普内容
- 需要同时生成文案和配套的AI绘图Prompt
- 需要把复杂技术用"类比"方式解释清楚

## Core Pattern

### 一、文案三要素

**1. 网感降维**
把技术概念翻译成人话，用生活化类比替代专业术语。
- ❌ "Agent是基于大模型的智能体，可自主决策"
- ✅ "Agent是能替你干活的'超级数字员工'"

**2. Emoji视觉断句**
用Emoji进行段落分隔，降低阅读压力。
- 每段开头用📚、🎯、🧑‍🏫等图标作为视觉标记
- 关键概念旁加Emoji辅助理解

**3. Call to Action引导互动**
结尾必须抛出问题，引导用户在评论区互动。
- 格式："👇 在评论区聊聊..."
- 目的：提升互动率，稳住流量

### 二、配图工作流

**核心原则：纯净底图资产 + 后期填字**

避免生图模型直接生成中文（容易出现错字），采用以下工作流：

| 步骤 | 操作 | 目的 |
|------|------|------|
| 1 | 生成无文字的纯净底图 | 避免中文错字 |
| 2 | 预留便利贴/横幅空间 | 后期填字 |
| 3 | 使用设计工具填字 | 保证文字清晰 |

**视觉风格规范**
- 比例：3:4竖版（小红书标准）
- 背景：米黄色做旧牛皮纸
- 线稿：深棕色钢笔线稿
- 色彩：低饱和水彩晕染
- 文字：手写体风格

**Midjourney Prompt模板**
```
小红书竖版3:4比例，手绘手账风格科普插画。米黄色做旧牛皮纸背景。
[画面顶部]：[横幅/便利贴，写着XXX]
[画面中央]：[主体构图描述]
[画面底部]：[批注/箭头指向的结论]
精致线稿，柔和水彩，留白干净。--ar 3:4 --stylize 150 --niji 6
```

### 三、合规要求

**标题规范**
- 严格控制在20字以内
- 包含痛点词 + 数字 + 核心概念

**敏感词过滤**
过滤以下词汇，替换为正向专业表达：
| 敏感词 | 替换词 |
|--------|--------|
| 牛马、打工人 | 助手、数字员工 |
| 老板、外包 | 指挥官、处理 |
| 掏空身体 | 烦扰 |

**排版规范**
- 便利贴设计便于后期填字
- 留足负空间（negative space）
- 信息密度高但不拥挤

## Quick Reference

### 类比转化模式
```
原概念 → 生活类比 → 大白话表达
AI训练 → 蒸馒头/教小孩上学 → 一步步引导学习
Agent → 超级实习生 → 能自己拆解任务的数字员工
模型蒸馏 → 老教授带小学生 → 老师傅手把手教
```

### 配图元素速查
- 封面图：对比构图（普通AI vs 升级版）
- 知识点图：单核心 + 图标气泡
- 结尾互动图：便利贴 + CTA + 咖啡/猫咪点缀

### 标签规范
```
#AI科普 #小白学AI #[具体概念] #大模型应用 #干货分享
```

## Common Mistakes

1. **跳过降维直接用术语** → 违背"用户思维"，小白看不懂
2. **标题超过20字** → 影响点击率
3. **让AI直接生成中文配图** → 出现错字"鬼画符"
4. **结尾无互动引导** → 流量留不住

## Real-World Impact

一个完整的笔记创作流程：
1. 收资：用户提供技术内容
2. 转化：降维成大白话 + 类比
3. 结构：①②③分段 + Emoji
4. 配图：5张手账风Prompt
5. 合规：过滤敏感词 + 标题≤20字
6. 发布：引导评论互动
