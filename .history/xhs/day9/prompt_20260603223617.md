## 🛠 配图工作流提醒

1. **生成底图**：把上述 Prompt 喂给 Midjourney / 即梦 / Liblib，**生成无文字的纯净图**
2. **后期填字**：用醒图 / 黄油相机 / Canva 添加便利贴文字
3. **比例统一**：3:4 竖版（小红书标准）
4. **风格统一**：米黄牛皮纸 + 棕色钢笔线稿 + 低饱和水彩
5. **避坑**：不要让 AI 直接生成中文（容易出现"鬼画符"）
