> **不要**让 AI 直接生成中文（容易出现"鬼画符"），但 Prompt 中可以写中文引导生成中文手写体氛围。

# 🛠 配图工作流（重要！）

1. **生成底图**：把上述 Prompt 喂给 **Midjourney / 即梦 / Liblib / DALL-E 3**
2. **生成时参数**：`--ar 3:4 --stylize 150 --niji 6`（风格统一）
3. **后期填字**：用 **醒图 / 黄油相机 / Canva** 添加中文便利贴文字
4. **比例统一**：3:4 竖版（小红书标准）
5. **风格统一**：米黄牛皮纸 + 棕色钢笔线稿 + 低饱和水彩
6. **避坑**：**不要**让 AI 直接生成中文（容易出现"鬼画符"）
7. **细节调整**：生成后可以微调 prompt，加更多"信息密度"关键词：
   - `highly detailed` `doodle style` `journal illustration`
   - `sticky notes` `high information density`
   - `color palette: beige + brown + muted watercolor`

## 🎨 备选风格切换（如不喜欢 niji 风）

- **更现代手账**：把 `--niji 6` 换成 `--v 6.1`
- **更卡通可爱**：加 `kawaii style, cute robot, pastel colors`
- **更硬核科普**：加 `infographic style, vector illustration, flat design`
- **更复古**：加 `retro 1960s style, vintage poster, mid-century modern`
