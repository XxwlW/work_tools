# 07-工具配图库

**主题**：通用资产（出图指南 / 配图 Prompt / 工具）

## 包含

- 各 day 的 `prompts/` / `prompts-v2/` 目录
- `出图指南.md`（每个 day 都有）
- `图.md` / `封面.png` / `1.png-7.png` 等图片资产
- day9 完整笔记模板

## 通用模板

每个主题目录的笔记统一结构：
- `笔记名-精华版.md` — 完整版
- `笔记名-精华正文-800字.md` — 直接发布版
- `笔记名-配图Prompt.md` — 5 张图英文 Prompt
- `prompts/` — 6-9 个独立 Prompt 文件
- `prompts/README.md` — 优化说明 + 校对报告

## 配图平台推荐

| 平台 | 中文错字率 | 推荐度 |
|------|----------|-------|
| 🥇 即梦 | < 5% | 最推荐 |
| 🥇 可灵 | < 5% | 最推荐 |
| ✅ DALL-E 3 | ~10% | 推荐 |
| ⚠️ Midjourney | ~30% | 慎用（中文易错）|
