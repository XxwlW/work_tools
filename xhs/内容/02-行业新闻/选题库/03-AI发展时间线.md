# 03-AI 发展时间线（深度素材库）

> **数据截止**：2026/6
> **置信度**：★★★（多源验证）
> **数据源**：Stanford AI Index / 中国信通院 / 国务院 / OpenAI 公告 / Anthropic 公告 / Google DeepMind
> **主研报背书**：[2026全球人工智能产业深度演进与跨行业系统性溢出效应研报](2026全球人工智能产业深度演进与跨行业系统性溢出效应研报：核心硬件瓶颈、生态重构与资本市场资产定价逻辑.md)（Gemini §1 智能经济 12.6 万亿 / 25.1% 占比 + 范式转移节点）

## 3.1 4 个发展阶段

| 阶段 | 时间 | 标志事件 | 算力规模 |
|---|---|---|---|
| **1. 深度学习萌芽** | 2012-2015 | AlexNet / AlphaGo | GPU 集群万卡 |
| **2. 预训练爆发** | 2017-2020 | Transformer / GPT-3 | 数千张 V100 |
| **3. 大模型时代** | 2020-2023 | GPT-3.5 / ChatGPT / GPT-4 | 2.5 万张 A100 |
| **4. 多模态 Agent** | 2024-2026 | GPT-4o / Claude 4 / Sora / Claude Code | 10 万+ H100/B200 |

## 3.2 完整时间线（2010-2026）

### 2010-2015 深度学习启蒙
- **2012**：AlexNet 在 ImageNet 比赛大胜（深度学习转折点）
- **2014**：Google 收购 DeepMind（£400M）
- **2015**：马斯克 / 奥特曼 / 霍夫曼 创立 OpenAI

### 2016-2020 预训练 + 大模型
- **2016**：AlphaGo 战胜李世石
- **2017**：Google 发布 Transformer 论文（"Attention is all you need"）
- **2018**：OpenAI GPT-1 / Google BERT
- **2019**：OpenAI GPT-2 / Nvidia 发布 Turing GPU
- **2020**：OpenAI GPT-3（1750 亿参数）

### 2021-2023 大模型商业化
- **2021**：OpenAI DALL-E / Nvidia 市值破 7000 亿
- **2022.11**：ChatGPT 发布（5 天 100 万用户，2 月 1 亿）
- **2023.3**：OpenAI GPT-4 / Anthropic Claude 2
- **2023.9**：OpenAI 创纪录融资 $10B（估值 $86B）
- **2023.11**：OpenAI 宫斗 / Sam Altman 被罢免又复职
- **2023.12**：Google Gemini 1.0

### 2024 多模态突破
- **2024.2**：OpenAI Sora（视频生成）
- **2024.3**：Nvidia Blackwell B200 发布（2080 亿晶体管）
- **2024.4**：Meta Llama 3（开源 70B）
- **2024.6**：Apple Intelligence 发布
- **2024.9**：OpenAI o1（推理模型）
- **2024.10**：Anthropic Claude 3.5 Sonnet
- **2024.11**：OpenAI Sora 正式版

### 2025 大模型 Agent 化
- **2025.1**：DeepSeek R1（开源推理模型，震惊硅谷）
- **2025.2**：阿里 Qwen3（千亿参数）
- **2025.3**：Anthropic Claude 4
- **2025.5**：Google Gemini 3.0
- **2025.6**：OpenAI GPT-5（多模态）
- **2025.10**：AI Agent 大爆发（Manus / Devin / Claude Code）
- **2025.12**：国家「智能经济」首次写入中央经济工作会议

### 2026 H1（截至 6 月）现状
- **2026.3**：Nvidia Blackwell Ultra 发布
- **2026.4**：Claude Code / Agent 普及
- **2026.5**：HBM4 量产
- **2026.6**：CoWoS 月产 4.5 万片 / Apple Intelligence 2.0
