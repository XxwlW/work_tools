## 出图自检清单

每张图出图后**逐项打勾**：

- [ ] 中文文字 0 错字（重点检查：智能经济、人工智能+、软智能体、硬智能体）
- [ ] emoji 正确显示（火 🔥、人群 👥、星 ✨、礼物 🎁）
- [ ] 关键词 0.5 秒可扫到（两会 / 智能经济 / 70% / 软 vs 硬 / 3 观察）
- [ ] 比例 3:4 竖版
- [ ] 主色调统一（暖白 + 中国红 + 焦糖橙 + 深灰黑）
- [ ] 无科技蓝紫 / 霓虹色 / 萌系元素
