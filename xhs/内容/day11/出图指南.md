## 🎨 各平台出图步骤（直接出中文）

### 方案 1：即梦 AI（推荐，中文场景最强）

**网址**：[jimeng.jianying.com](https://jimeng.jianying.com/)

**步骤**：
1. 打开即梦网页版
2. 点"AI 生图"
3. 选比例 **3:4**（竖版）
4. 选风格 **"卡通手绘"** 或 **"手账风"**
5. **打开 9.1-封面-5大Agent擂台.md** → 复制 ## Prompt 段落
6. 粘贴到文本框
7. 点生成（等 1-3 分钟）
8. 下载 PNG

**注意**：即梦对中英文混合 prompt 识别极好，几乎 100% 准确画出中文

---

### 方案 2：可灵 AI（快手，推荐）

**网址**：[klingai.kuaishou.com](https://klingai.kuaishou.com/)

**步骤**：
1. 打开可灵网页版
2. 点"AI 生图"
3. 选比例 3:4
4. 复制 9.1-9.9 任一 Prompt 段落
5. 粘贴生成
6. 下载

**优势**：中文渲染最稳，错字率最低

---

### 方案 3：Midjourney（细节最好）

**步骤**：
1. Discord 进 Midjourney 频道
2. 输入 `/imagine`
3. 复制 9.1 prompt（举例）
4. **末尾必须加参数**：`--ar 3:4 --stylize 150 --niji 6`
5. 等 60 秒
6. U1-U4 选最满意的一张放大
7. 下载

**MJ 的中文问题**：
- ⚠️ MJ v6 对中文支持一般，可能出现**错字**（"大乱斗"写成"大乱斗"的概率约 70%）
- 建议用 `--v 6.1` 替代 `--niji 6`，中文稍微准一点
- 如果错字严重，**改用即梦/可灵**

---

### 方案 4：DALL-E 3（ChatGPT Plus / Bing）

**步骤**：
1. 打开 ChatGPT（Plus 会员）或 Bing Image Creator（免费）
2. 把 9.1 prompt 复制
3. 选尺寸 **1024x1792**（3:4）
4. 等 30-60 秒
5. 下载

**DALL-E 3 的中文**：
- ✅ ChatGPT 4 内置 DALL-E 3 对中文支持**很好**（OpenAI 用专门的字形渲染）
- ⚠️ 但偶尔会**自创文字**（不是错字，是编造）
- 解决方案：发现编字就重新生成

---

### 方案 5：Liblib / Stable Diffusion

**网址**：[liblib.art](https://liblib.art/)

**步骤**：
1. 注册登录
2. 进"在线生图"
3. 选 SD 1.5 / SDXL / Pony 模型
4. **基础 Prompt**：复制 9.1 prompt
5. **负面 Prompt**（必须加）：
   ```
   text, watermark, signature, blurry, low quality,
   deformed hands, extra fingers, ugly
   ```
6. **不建议用 SD 出中文**（SD 对中文支持极差，几乎 100% 错字）

**SD 的中文**：
- ❌ **不推荐用 SD 出中文文字**（错字率 80%+）
- ✅ 建议用法：SD 出底图（无文字）+ 醒图后期加中文

## 🔄 错字修复技巧

**如果生成的中文有错字**：

### 方案 A：重新生成（最简单）
- 同样的 Prompt 再点一次"生成"
- 错字是随机的，第二次可能就对了
- 建议每张图生成 2-3 次选最佳

### 方案 B：换平台
- MJ 出错字 → 切换即梦
- 即梦出错字 → 切换可灵

### 方案 C：后期修补
1. 用醒图打开图
2. 点"消除"或"马赛克"盖住错字
3. 点"文字" → "花字" 重新打正确文字
4. 调整字体和颜色匹配

### 方案 D：备份方案（最稳）
- **降级回 v1 模式**：Prompt 改成不含中文，出无文字底图
- 然后用醒图/黄油相机后期加中文
- 永远不会出错字

## 🆘 常见问题

**Q：出的图有错字？**
A：① 重新生成（错字是随机的） ② 换平台（即梦/可灵最稳）③ 后期修补

**Q：出的图不像手账风？**
A：在 prompt 前面强制加：
```
Hand-drawn bullet journal style, beige kraft paper,
dark brown pen line art, low-saturation watercolor wash
```

**Q：出的图人脸/手变形？**
A：负面 prompt 加：`deformed, ugly, bad anatomy, extra fingers, blurry`

**Q：出的图中文字太小看不清？**
A：在 Prompt 里加：`bold large Chinese text, high contrast, clear typography`

**Q：9 张图都要出吗？**
A：不一定。**必出**：9.1 封面 + 9.7 对比表 + 9.8 选择指南
**可选**：9.2-9.6 单 Agent 卡片（发"深度版"笔记时再用）
**互动**：9.9 互动图（想冲评论时加）
