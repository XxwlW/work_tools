🦞 **【OpenClaw】开源小龙虾，免费到飞起**
由奥地利程序员 **Peter Steinberger**（PSPDFKit 创始人）开发的开源项目，MIT 协议。
2026-02 成立 **OpenClaw Foundation** 非营利组织接管，创始人同时加入 OpenAI。
口号是"**The AI that actually does things**"——能写代码、清邮箱、排日程、控制浏览器。

**数据炸裂**（2026-06-04 实时核验）：
- **GitHub Stars：376,762**（3 个月 +52%）
- **Forks：78,731**
- **最新版：v2026.6.1**（2026-06-03 发布）
- **支持 30+ 平台**：27 个聊天软件（微信、QQ、WhatsApp、Telegram、Discord、Slack、Signal、iMessage、飞书、钉钉、IRC、Teams、Matrix、Nostr、Twitch……）+ 3 个 OS（macOS/Linux/Windows）

**特色**：
- **soul.md 人设卡**（写几行 Markdown 就定 AI 性格）
- **100+ 技能插件**（ClawHub 技能市场，VirusTotal 扫描）
- **自托管 + 跨平台聊天**

**类比**：**住在你 Mac mini 里的 24 小时全能助理**

**超爆冷知识** 🦞：这项目**2 个月内换了 4 个名字**！
- 2025-11-24：**Warelay**（原始名）
- 2025-12-03：**CLAWDIS**
- 2026-01-02：**Clawdbot**
- 2026-01-27：**Moltbot**（Anthropic 商标投诉后改名）
- 2026-01-30：**OpenClaw**（再改一次）
吉祥物叫 **Molty** 🦞——一只"有灵魂的太空龙虾"！

☁️ **【Codex】OpenAI 的云端打工人**
老牌 AI 编程 Agent，2021 年出道就是 GitHub Copilot 的底座。
2025-05 重启为"云端 Agent"，2026 年快速进化。

**数据炸裂**（2026-03 核验）：
- **周活用户：200 万+**（2026-03 同比 2026 年初 5 倍）
- **100 万+ 开发者**用过
- **最新模型：GPT-5.4 for Codex**（2026-03-05 发布）
- **GPT-5.3-Codex-Spark**（Cerebras 硬件加速，~15× 速度，2026-02-12）
- **桌面 App** 已发布（macOS + Windows，2026-02-02）
- **Codex Security** 已发布（30 天扫 120 万 commit，找 800 严重漏洞）

**特色**：
- 集成在 ChatGPT Plus/Pro/Enterprise
- 异步任务：你提需求 → 云端沙箱跑 → 给你交 PR
- 企业客户：Cisco、Nvidia、Ramp、Rakuten、Harvey

**类比**：**美团跑腿代下单**——下完单你走开，回来收货

💻 **【Claude Code】程序员的贴身秘书**
Anthropic 出品，2025-02 首发研究预览，2025-05 GA 与 Claude 4 同步。

**数据炸裂**（2026-06 核验）：
- **最新模型：Claude Opus 4.8**（2026-05-28 发布）
- **Sonnet 4.6**（2026-02-17）、**Opus 4.6**（2026-02-05）
- **SWE-bench 长期霸榜**
- **2025-07 企业收入增长 5.5 倍**
- **微软 / Google / OpenAI 内部都在用**
- **Opus 4.7 限 11 家企业（Project Glasswing）**（2026-04-07）

**特色**：
- 终端里跑，能读全仓库、跑测试、自动改 bug、自动提 PR
- 2026-03-24 推出手机 Agent 功能
- 2025-12 NASA 火星车用 Claude Code 规划 400m 路线 🚀

**类比**：**贴身私人秘书**——全程在你旁边一起干活

🐳 **【DeepSeek Agent】国产之光，600 万训出万亿模型**
