## 🚨 v4 极简封面（必看！解决点击率 7% 问题）

### 小红书官方诊断

> "该笔记封面点击率仅超过 5% 的同类笔记...画面元素过于繁杂。五个机器人 + 大量标签文字 → 视觉重心分散。关键信息(大乱斗、真王者)容易被细节淹没。"
>
> **建议**：保留手绘风格，但**大幅简化封面构图**。只保留**1 个最具代表性的视觉主体**，并将**标题字号放大**。

**步骤**：

2. 点"AI 生图"

5. **打开 8.1-封面-3步+24h数字员工.md** → 复制 ## Prompt 段落

7. 点生成（等 1-3 分钟）

**注意**：即梦对中英文混合 prompt 识别极好，几乎 100% 准确画出中文

### 方案 2：可灵 AI（快手，推荐）

**步骤**：
1. 打开可灵网页版
2. 点"AI 生图"

### 方案 3：Midjourney（细节最好）

**步骤**：
1. Discord 进 Midjourney 频道
2. 输入 `/imagine`
3. 复制 8.1 prompt（举例）
4. **末尾必须加参数**：`--ar 3:4 --stylize 150 --niji 6`
5. 等 60 秒

**MJ 的中文问题**：

**步骤**：

**DALL-E 3 的中文**：

- ⚠️ 但偶尔会**自创文字**（不是错字，是编造）

### 方案 5：Liblib / Stable Diffusion

## 🔄 错字修复技巧

**如果生成的中文有错字**：

### 方案 A：重新生成（最简单）
- 同样的 Prompt 再点一次"生成"
- 错字是随机的，第二次可能就对了
- 建议每张图生成 2-3 次选最佳

### 方案 B：换平台
- MJ 出错字 → 切换即梦
- 即梦出错字 → 切换可灵

### 方案 C：后期修补
1. 用醒图打开图
2. 点"消除"或"马赛克"盖住错字
3. 点"文字" → "花字" 重新打正确文字
4. 调整字体和颜色匹配

### 方案 D：备份方案（最稳）
- **降级回 v1 模式**：Prompt 改成不含中文，出无文字底图
- 然后用醒图/黄油相机后期加中文
- 永远不会出错字
